# SaunaWhisks.com

Next.js site for SaunaWhisks.com — a Latvia-based sauna-whisk brand and knowledge platform focused on Baltic sauna and banya traditions.

## Development

```bash
npm install
npm run dev
```

## Deployment

Designed for Vercel. Connect the GitHub repository to Vercel and deploy the `main` branch.

## Current status

Phase 1 brand/landing-page foundation. Commerce, CMS, product data, checkout and verified supplier/heritage content will be added in later phases.
