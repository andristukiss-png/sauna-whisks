# Trade trial process

A first B2B order should create data, not just revenue.

Track:
- venue / retailer type
- materials tested
- units supplied
- preparation time
- staff ease-of-use
- leaf retention
- customer/guest feedback
- waste/damage
- stock consumption
- preferred material
- expected reorder volume

Use the public CSV template at:

`/api/trade-trial-template.csv`
