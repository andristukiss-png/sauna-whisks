# Commercial launch checklist

Checkout stays disabled until the critical gates below are complete.

## Product
- [ ] Final launch SKUs selected
- [ ] Supplier identity verified internally
- [ ] Botanical material/species recorded where available
- [ ] Harvest origin recorded
- [ ] Production origin recorded
- [ ] Product condition confirmed (dried/frozen/etc.)
- [ ] Length/weight tolerance measured
- [ ] Preparation instructions tested
- [ ] Leaf-retention test completed
- [ ] Packaging specification approved

## Compliance
- [ ] EU selling entity/legal details finalized
- [ ] VAT treatment confirmed
- [ ] Returns/cancellation policy finalized
- [ ] Privacy notice finalized
- [ ] Destination import requirements checked per SKU
- [ ] Required supplier/export documentation identified

## Commercial
- [ ] Wholesale cost confirmed
- [ ] Inbound freight known
- [ ] Packaging cost known
- [ ] Fulfilment cost known
- [ ] Payment processing modeled
- [ ] Shipping subsidy/free-shipping threshold decided
- [ ] Final retail prices approved
- [ ] Contribution margin model approved

## Technical
- [ ] GitHub connected directly to Vercel
- [ ] Production build passes CI
- [ ] Enquiry email provider configured
- [ ] SaunaWhisks.com sender domain verified
- [ ] Checkout/payment provider configured
- [ ] Analytics/privacy configuration reviewed
- [ ] Test order completed end-to-end
