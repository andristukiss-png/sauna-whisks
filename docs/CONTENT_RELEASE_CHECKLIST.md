# Content release checklist

Before publishing a new guide/page:

- user intent is distinct from existing content
- title and description are clear
- canonical route set
- sources support factual claims
- tradition-specific wording is not generalized carelessly
- no unsupported health claim
- commercial assumptions labeled planned/pre-launch
- useful next-step links included
- sitemap/search/hub coverage added when relevant
- build checks pass
