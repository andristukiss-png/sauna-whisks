# Content publishing guide

Every factual article should answer:

1. What is the exact user question?
2. Is this tradition-specific or general?
3. Which statements require a source?
4. Are commercial assumptions clearly labeled as planned/pre-launch?
5. Are medical/therapeutic claims avoided?
6. Does the article link to a useful next step?
7. Does another existing page already target the same intent?

## Sources
Prefer:
- official sauna organizations
- government/cultural institutions
- official import/regulatory authorities
- named producers for product-specific claims

Marketplace evidence can demonstrate commercial presence but should not be presented as scientific or regulatory evidence.
