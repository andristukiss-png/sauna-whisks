# Site architecture

## Strategic model
Sauna whisks are the hero category and acquisition hook. Education explains the unfamiliar category; commerce converts that understanding into a product, bundle or enquiry.

Longer term, adjacent sauna-ritual products may be added only after sourcing, compliance, margin and brand-fit validation.

## Commercial
Shop → Product → Comparison / Finder / Enquiry

Future expansion path:
Whisks → Sets / Multipacks → Preparation / Storage → Textiles / Hats → Botanical aroma products → Gifts → Repeat / Subscription

## Learning
Learn → Beginners / Materials / Conditions / Care / Traditions / Journal / Glossary

The learning layer should answer:
What is it? → Which term/material? → How do I prepare/use/store it? → Which product fits me?

## Authority
Quality → Standards / Operations / Claims / Sources / Product data / Checklist

## B2B
Trade → segment pages → trial → wholesale enquiry

## Supply
Suppliers → requirements → sample evaluation → supplier enquiry

## Markets
Markets → country status → market enquiry

The US is a priority category-education and commercial research market; see `docs/STRATEGY.md`.

## Trust
About / Status / Legal / Shipping / Privacy / Terms / Returns / Accessibility

## Machine-readable
Sitemap / feeds / public JSON+CSV APIs / llms.txt / security.txt
