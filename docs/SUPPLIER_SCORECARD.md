# Supplier scorecard

Score each candidate on evidence, not presentation.

| Area | Questions |
|---|---|
| Origin | Where are branches harvested? Can this be documented? |
| Botanical detail | What species/material is used? |
| Harvest | When is production performed? Is season/date recorded? |
| Processing | Fresh, dried, frozen, vacuum-packed or other? |
| Quality | How are branch selection, tying and drying controlled? |
| Consistency | Are dimensions and weight reasonably consistent? |
| Leaf retention | How does the whisk perform after correct preparation? |
| Packaging | How are leaves protected for export? |
| Capacity | MOQ, normal order volume, annual capacity, lead time? |
| Export | Existing export markets? Phytosanitary/documentation experience? |
| Responsiveness | Can the supplier answer technical questions clearly? |
| Traceability | Is batch/harvest information available? |

## Suggested internal scoring
Use 1–5 per area and keep notes/evidence links beside every score.

Do not award points for unverified heritage claims.
